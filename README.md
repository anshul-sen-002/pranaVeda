# Pranaveda 🌿

Pranaveda is a wellness platform focused on yoga, meditation, and holistic well-being. It provides users with a space to explore yoga practices, access wellness resources, and build healthy daily habits.

## ✨ Features

- **Yoga Library** – Explore yoga practices and asanas.
- **Wellness Resources** – Access yoga videos, articles, and audio content.
- **User Authentication** – Secure registration and login.
- **Personal Dashboard** – Manage saved content and track wellness activities.
- **AI Wellness Assistant** – Get guidance related to yoga and wellness.
- **Admin Dashboard** – Manage yoga content and platform resources.
- **Responsive UI** – Designed for desktop and mobile devices.

## 🛠️ Tech Stack

**Backend**
- Java
- Spring Boot
- Spring Security
- Spring Data JPA

**Frontend**
- Next.js
- React
- TypeScript
- Tailwind CSS

**Database & Services**
- PostgreSQL
- Cloudinary

## 🏗️ Architecture

The application follows a client-server architecture:

- Next.js handles the frontend and user interface.
- Spring Boot manages business logic and REST APIs.
- PostgreSQL stores application data.
- Cloudinary manages media assets.

## 🚀 Getting Started

### Prerequisites

- Java 21+
- Node.js
- PostgreSQL
- Maven
- npm

### Backend Setup

```bash
git clone <repository-url>
cd pranaveda/backend
```

Configure your database credentials and environment variables, then run:

```bash
mvn spring-boot:run
```

### Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

Open `http://localhost:3000` in your browser.

## 🎯 Project Goal

The goal of Pranaveda is to make yoga and holistic wellness more accessible through technology, encouraging users to develop healthier lifestyles and consistent wellness habits.
